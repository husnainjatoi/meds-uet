# Lecture Notes

This directory contains concise summaries of the lectures delivered during the **MEDS UET Summer Training Program**.

The notes are intended as a quick reference for revision and focus on the major concepts covered in each lecture rather than serving as complete transcripts. They were prepared to reinforce understanding of digital design, computer architecture, hardware description languages, timing analysis, and verification.

## Lecture Overview

| Lecture | Topics Covered |
|---------|----------------|
| **Lecture 1** | Fundamentals of Computer Architecture, Transformation Hierarchy, Transistors, CMOS Logic |
| **Lecture 2** | Combinational Logic, Boolean Algebra, Logic Optimization, Decoders, Multiplexers, Adders |
| **Lecture 3** | Sequential Logic, Latches, Flip-Flops, Registers, Memory, Finite State Machines |
| **Lecture 4** | FSM Implementation, State Encoding, Moore vs. Mealy Machines, FPGAs, Verilog Fundamentals |
| **Lecture 5** | Verilog Modeling Styles, Sequential Logic in HDL, FSM Design in Verilog, Blocking vs. Non-Blocking Assignments |
| **Lecture 6** | Timing Analysis, Propagation & Contamination Delay, Setup & Hold Time, Clock Skew, Circuit Verification |

## Purpose

These notes were created to:

- Summarize key concepts from each lecture.
- Provide a quick revision guide.
- Capture important definitions, design principles, and implementation techniques discussed during the training.
- Serve as a reference while completing the practical modules and projects.
