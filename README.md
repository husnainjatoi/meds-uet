# Maktab-e-Digital Systems Training

This repository contains my practice material, exercises, notes, and code developed during the **MEDS Summer Training Program 2026**.

The repository is organized by training modules, with each module placed in its own directory. These folders contain the practice work, examples, and learning resources completed throughout the program.

> **Note:** The complete projects developed during the training are maintained in their own independent GitHub repositories. This repository serves as a collection of module-wise learning material rather than the final project implementations.

---

## Repository Structure

```
meds-uet/
├── c_language/
├── lecture-notes/
├── riscv_assembly/
├── shellscripting/
└── systemverilog/
```

Each directory contains its own documentation (`README.md`) describing the module contents, exercises, and internal file structure.

---

## Modules

| Module | Description |
|---------|-------------|
| **Lecture Notes** | Notes and summaries prepared during the training sessions. |
| **Shell Scripting** | Linux shell scripting examples and automation practice. |
| **C Language** | Programming exercises, examples, and practice material covering C language fundamentals. |
| **RISC-V Assembly** | Assembly programming exercises and practice for the RISC-V instruction set architecture. |
| **SystemVerilog** | Digital design, verification, and hardware description language practice exercises. |
