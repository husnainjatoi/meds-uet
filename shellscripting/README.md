# Shell Scripting

This directory contains shell scripting exercises completed during the **Maktab-e-Digital Systems Summer Training Program**.

The scripts demonstrate fundamental Linux shell scripting concepts, including file management, automation, text processing, and utility development. Each script focuses on solving a practical task using Bash.

## Contents

```text
shellscripting/
├── batch_rename.sh
├── file_stats.sh
├── organizer.sh
└── sim_checker.sh
```

## Script Overview

| Script | Description |
|---------|-------------|
| **batch_rename.sh** | Batch renames multiple files using a consistent naming scheme. |
| **file_stats.sh** | Displays useful statistics and information about files or directories. |
| **organizer.sh** | Automatically organizes files into directories based on predefined criteria. |
| **sim_checker.sh** | Utility script for checking simulation outputs and reporting results. |

## Topics Covered

- Bash scripting fundamentals
- Variables and command-line arguments
- Conditional statements (`if`, `case`)
- Loops (`for`, `while`)
- Functions
- File and directory operations
- Text processing utilities
- Process automation
- Linux command-line tools

## Purpose

These scripts were developed to:

- Practice Bash scripting and Linux command-line usage.
- Automate repetitive tasks.
- Reinforce shell programming concepts through hands-on exercises.
- Build practical utilities commonly used in development workflows.

## Requirements

- Linux or WSL
- Bash Shell

Run a script using:

```bash
chmod +x script_name.sh
./script_name.sh
```

These scripts are educational exercises created during the Maktab-e-Digital Systems Summer Training Program and are intended for learning and practice purposes.
