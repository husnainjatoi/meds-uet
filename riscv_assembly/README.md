# RISC-V Assembly

This directory contains RISC-V assembly programs and reference material completed during the **Maktab-e-Digital Systems Training Program**.

The exercises focus on implementing common algorithms, understanding the RISC-V instruction set architecture (ISA), and developing low-level programming skills. In addition to programming exercises, this directory also includes concise summaries of important RISC-V architecture concepts covered during the training.

## Contents


## Program Overview

| File | Description |
|------|-------------|
| **array_sum.s** | Computes the sum of all elements in an array. |
| **binary_search.s** | Implements the binary search algorithm on a sorted array. |
| **bubble_sort.s** | Sorts an array using the Bubble Sort algorithm. |
| **factorial.s** | Calculates the factorial of a number. |
| **find_max_array.s** | Finds the maximum value stored in an array. |
| **max_sum_array.s** | Computes the maximum sum from an array according to the exercise requirements. |
| **recursive_fibonacci.s** | Generates Fibonacci numbers using recursion. |
| **recursive_power.s** | Computes the power of a number recursively. |
| **sign_checker.s** | Determines whether a number is positive, negative, or zero. |
| **EXTENSION_SUMMARY.md** | Summary of the RISC-V Compressed (C) Extension. |
| **privileged_summary.md** | Summary of the RISC-V Privileged Architecture and related concepts. |

## Topics Covered

- RISC-V instruction set architecture (RV32I)
- Assembly programming fundamentals
- Arithmetic and logical instructions
- Branching and control flow
- Loops and conditional execution
- Functions and procedure calls
- Recursion
- Stack management
- Memory addressing
- Arrays and pointer manipulation
- Sorting and searching algorithms
- RISC-V ISA extensions
- Privileged architecture

## Purpose

These programs and notes were developed to:

- Gain hands-on experience with RISC-V assembly programming.
- Understand how high-level algorithms are implemented at the instruction level.
- Strengthen knowledge of processor architecture and instruction execution.
- Practice debugging and analyzing low-level software.
- Build a foundation for processor design and computer architecture.

## Requirements

- RISC-V simulator (e.g., Venus or RARS)

Load an assembly program into your preferred simulator and assemble/run it according to the simulator's instructions.
