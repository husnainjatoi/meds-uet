# C Language

This directory contains C programming exercises completed during the **Maktab-e-Digital Systems Summer Training Program**.

The programs focus on applying core C programming concepts to problems commonly encountered in computer architecture, digital systems, and low-level software development. Each exercise is designed to strengthen understanding of how software interacts with hardware.

## Contents

```text
c_language/
├── cpu_state.c
├── hex_converter.c
├── instruction_parser.c
├── memory_controller.c
└── register_file.c
```

## Program Overview

| Program | Description |
|---------|-------------|
| **cpu_state.c** | Simulates CPU state management using structures and state variables. |
| **hex_converter.c** | Converts numerical values between hexadecimal and other representations. |
| **instruction_parser.c** | Parses and decodes instruction fields from user-provided input. |
| **memory_controller.c** | Implements basic memory read and write operations, simulating a simple memory controller. |
| **register_file.c** | Simulates a CPU register file with register access and data manipulation operations. |

## Topics Covered

- C programming fundamentals
- Variables and data types
- Functions
- Arrays and strings
- Pointers
- Structures
- Bitwise operations
- Input and output
- Control flow
- Memory and register simulation

## Purpose

These programs were developed to:

- Strengthen core C programming skills.
- Apply programming concepts to hardware-oriented problems.
- Gain practical experience with low-level software development.
- Build a foundation for computer architecture and embedded systems.

## Requirements

- GCC or any C99-compatible compiler

Compile and run a program using:

```bash
gcc program_name.c -o program_name
./program_name
```

These programs are educational exercises created during the MEDS Summer Training Program and are intended for learning and practice purposes.
